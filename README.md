## 🎯 Seçilen Problem: Sürekli Ertelenen Görevler (Problem 3)

Geleneksel planlayıcılar sadece "ne yapmanız gerektiğini" söyler. **Zenith** ise "neden yapmadığınızı" anlar.
Kullanıcılar genellikle mental yük, belirsizlik veya yorgunluk nedeniyle görevleri erteler. Bu durum zamanla görevlerin psikolojik olarak daha büyük görünmesine neden olur. Zenith:
- Erteleme davranışlarını ve nedenlerini analiz eder.
- Görevleri atomik ve uygulanabilir parçalara böler.
- Kullanıcıyı yargılamadan, "AI Mentor" yaklaşımıyla küçük başlangıç adımları (micro-steps) sunar.

### 4.2. Sonuç
Zenith, yapay zekayı sadece bir araç olarak değil, bir koç olarak konumlandırır. İnsan psikolojisini merkeze alan bu yaklaşım, dijital planlayıcı dünyasında yeni bir standart belirler.

## ✨ Öne Çıkan Özellikler

### 🌿 Habit Garden (Alışkanlık Bahçesi)
Alışkanlıklarınızı bir bahçe gibi büyütün. Her tamamlanan rutin, dijital bahçenizde yeni bir bitki yeşertir. Görselleştirilmiş ilerleme ile motivasyonunuzu zirvede tutun.

### 🤖 AI Mentor & Procrastination Analysis
Yapay zeka asistanınız, erteleme geçmişinizi analiz ederek size özel stratejiler geliştirir:
- "Bu raporu 3 kez erteledin. Gel sadece ilk paragrafı 5 dakikada yazalım."
- Mental yorgunluk tespiti ve dinlenme önerileri.

### 📊 Comprehensive Dashboard
- **Bütçe Yönetimi:** Finansal durumunuzu takip edin.
- **Uyku Takibi:** Dinlenme kalitenizi analiz edin.
- **Günlük Akış:** Tüm hayatınızı tek bir şık arayüzden yönetin.

## 🛠️ Teknoloji Yığını

- **Frontend:** Next.js 15 (App Router), TypeScript, Tailwind CSS
- **State Management:** Custom React Hooks & Context API
- **AI Engine:** OpenAI API (GPT-4o & Vision)
- **Styling:** Glassmorphism UI, Framer Motion (Akıcı animasyonlar)
- **Data Persistence:** LocalStorage & Session Management

## 🚀 Kurulum ve Çalıştırma

1. Projeyi klonlayın:
   ```bash
   git clone https://github.com/asilkorayalma/hackatohonnn.git
   ```
2. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```
3. `.env.local` dosyasını oluşturun ve OpenAI API anahtarınızı ekleyin:
   ```env
   OPENAI_API_KEY=
   ```
4. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```
