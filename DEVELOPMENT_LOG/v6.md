### 1.2 Günlük Streak Pill'i
Erteleme pill'inin yanına **aynı boyutta** ikinci bir bilgi rozeti.

**Hesaplama mantığı (`computeStreak`):**
- Bugünden geriye doğru gün gün taranır (en fazla 365 gün)
- Sadece `kind === 'task'` öğeler dikkate alınır
- O günün **tüm task'ları tamamlanmışsa** streak +1
- O günde hiç task yoksa → atlanır (streak kırılmaz, sayılmaz)
- Eski bir günde tamamlanmamış task varsa → **streak kırılır**
- **Bugün özel durumu**: Bugünün tüm task'ları tamamlanmadıysa streak kırılmaz, sadece sayılmaz (gün henüz bitmemiş olabilir)

**Görsel tonlar:**

| Streak | Lucide ikon | Ton | Renk |
|---|---|---|---|
| 0 | `Target` | `muted` | gri |
| 1–6 | `Flame` | `live` | mavi |
| 7+ | `Flame` (drop-shadow glow) | `hot` | turuncu→kırmızı gradient |

- "Bugün tüm görevler tamam" durumunda pill sonunda küçük dolu nokta (`csp-dot`)
- Aynı `#postponeSection`'a scroll eder (orada zaten "Gün Streak" kartı var)

### 2.3 Maskeleme Stratejisi
İlk yaklaşım: "ilk yarısı görünür, ikinci yarısı `•`" (yarı maskeli). Kullanıcı **çok agresif olmadığını** belirtti → `maskHalf` yerine `maskKey`'e geçildi:

```
sk-proj-abc123def456ghi789jkl012XYZ4  →  sk-proj-••••••••••••XYZ4
sk-abcdef1234ghij5678                 →  sk-••••••••••••5678
```

Kurallar:
- `sk-proj-` ile başlıyorsa → 8 karakter prefix görünür
- `sk-` ile başlıyorsa → 3 karakter prefix
- Diğer formatlar → ilk 3 karakter
- **Sabit 12 nokta** (anahtarın gerçek uzunluğunu sızdırmaz)
- Son 4 karakter görünür (anahtarı tanımlamaya yeter)
- 8 karakterden kısa key → tamamen maskeli

## 🆕 Aşama 4 — İstatistikler: AI Özet Gerçeğe Bağlandı

### 4.1 Sorun Tespiti
`src/components/StatisticsOverlay.tsx` mevcut hâlinde:
- Özet metni **hard-coded**: *"Bu hafta toplam 12 görev tamamladınız. Rutinlerinize sadık kalma oranınız %85..."* — gerçek event verisinden hesaplanmıyordu

### 4.2 `computeWeekStats` Fonksiyonu
Geçerli haftadaki gerçek istatistikleri çıkarır:

| Alan | Açıklama |
|---|---|
| `weekRange` | Örn. "10.5 - 16.5.2026" |
| `total` / `completed` / `uncompleted` | Hafta içi görev sayıları |
| `completionRate` | 0-100 yüzde |
| `totalPostpones` / `chronicCount` | Hafta içi erteleme metrikleri |
| `topReasons` | En sık ilk 3 erteleme nedeni (insancıl etiketle) |
| `topPostponed` | En çok ertelenen ilk 3 görev |
| `byCategory` | `{ category, total, completed }` dağılımı |

### 4.3 Fallback Özet
API key yokken bile kart **boş kalmasın** diye `buildFallbackSummary(stats)` türünde hesaplanmış kısa bir özet gösteriliyor. AI cevabı geldiğinde onunla değişir.

### 4.4 Türkçe Prompt
`buildPrompt(stats)` 3-5 cümle, samimi-koç tonunda Türkçe akıcı paragraf isteyen bir prompt üretir:
1. 1 cümle genel değerlendirme
2. 1-2 cümle güçlü yan
3. 1-2 cümle nazik öneri
4. Madde işareti / başlık yok

### 4.5 UI State Makinesi
```ts
type AiState =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'ok'; text; model }
  | { status: 'error'; message }
```

Davranışlar:
- **Loading**: Loader2 spinning + "AI özet hazırlıyor…"
- **Idle/Fallback**: hesaplanmış kısa özet
- **OK**: AI metni + altta `Model: gpt-4o-mini` etiketi
- **Error**: kırmızı kutu (key yoksa: *"Sol menüden ⚙️ Ayarlar → OpenAI API Key bölümünden ekleyebilirsin."*)
- Buton metni adaptif: "Özeti Üret (AI)" → "Hazırlanıyor…" → "Yeniden Üret"

### 4.6 PDF / E-posta — "Yakında" Tasarımı
Kullanıcı talebi: "**çok yakında bir tasarım olarak ekle, basılamasın**".

Sağ kart yeniden tasarlandı:

- İki buton (`FileDown` PDF + `Mail` E-posta) — `disabled`, `pointer-events:none`
- Görsel: gri/dashed border, hover efekti yok, imleç `not-allowed`
- Alt yazı: *"Bu özellikler yakında eklenecek."*

const handleLoadScenario = useCallback(() => {
