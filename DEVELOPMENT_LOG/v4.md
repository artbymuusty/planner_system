# 🧱 v4 — Veri Modeli Genişletmesi & Çoklu-Tür Ekleme Akışı

## Genel Bilgi

### 📅 Tarih: 10 Mayıs 2026
### 👤 Geliştirici: Umut
### 🎯 Hedef
Problem 3 (Sürekli Ertelenen Görevler) çözümüne geçmeden önce **ekleme akışını sağlam zemine oturtmak**. Mevcut sistem her şeyi tek tip "saatli etkinlik" olarak ele alıyordu; bu yüzden saatsiz görevler, büyük hedefler ve tekrar eden işler düzgün modellenemiyordu. Önce veri modelini, sonra modal akışını, en sonunda calendar görselini güncelledik.

Bu v4, üç aşamadan oluşur:
- **Aşama 1**: Veri modeli + storage migration
- **Aşama 2**: AddEventModal'ın 3 sekmeli (Etkinlik / Görev / Hedef) yapıya geçişi
- **Aşama 3**: Calendar görselinin çoğullaştırılması (all-day shelf, kind/category stilleri, hover aksiyonları, slot tıklama)

## 🆕 Aşama 1 — Veri Modeli Genişletmesi

### 1.1 `PlannerEvent` Zenginleştirildi
`src/types/index.ts` içinde `PlannerEvent`'e şu alanlar eklendi:

| Alan | Tip | Anlamı |
|---|---|---|
| `kind` | `'event' \| 'task' \| 'goal'` | Öğenin türü |
| `category` | `'personal' \| 'work' \| 'study' \| 'health' \| 'other'` | Kategori (sidebar filtreleri için) |
| `estimatedMin?` | `number` | Tahmini süre — slot'tan bağımsız |
| `allDay?` | `boolean` | Saatsiz görev mi? |
| `recurrence?` | `{ pattern, until? }` | Tekrar paterni (`daily` / `weekdays` / `weekly`) |
| `completedDates?` | `string[]` | Tekrarlayan görevde hangi günler tamamlandı |
| `description?` | `string` | Hedef için açıklama alanı |

Yardımcı tipler de export edildi:
- `EventKind`, `EventCategory`
- `Recurrence`, `RecurrencePattern`

### 1.2 Sabitler ve Etiketler
`src/lib/constants.ts` içine eklenenler:
- `EVENT_KIND_LABELS` ve `EVENT_KIND_HINTS` — modal sekmeleri için
- `EVENT_CATEGORY_LABELS`, `EVENT_CATEGORY_ICONS`, `EVENT_CATEGORY_COLORS` — UI'da kategori gösterimi
  - Kişisel `#6366f1` (indigo), İş `#0ea5e9` (sky), Okul `#a855f7` (purple), Sağlık `#10b981` (emerald), Diğer `#64748b` (slate)
- `ESTIMATED_MIN_OPTIONS` — 15 dk / 30 dk / 1 sa / 2 sa / 4 sa preset'leri
- `RECURRENCE_LABELS` — Türkçe etiketler

### 1.3 Storage Migration
`src/lib/storage.ts` içinde `migrateEvent()` fonksiyonu yazıldı:
- Eski localStorage kayıtlarını yüklerken eksik alanları default değerlerle dolduruyor
- Modül kaynaklı event'lere akıllı kategori atıyor: `birthday → personal`, `medicine → health`
- Saat alanı boşsa otomatik `allDay: true` çıkarımı yapıyor
- Bozuk/eksik kayıtlar `null` döner ve süzülür → app eski veriyle çakışmadan açılıyor

### 1.4 Mevcut Üretim Yerleri Güncellendi
- `AddEventModal`: yeni event'lere `kind: 'event'`, `category: 'personal'` default'u eklendi
- `PlannerApp.handleSplitConfirm`: alt görevler artık `kind: 'task'` ve parent'ın `category`'sini miras alıyor; `estimatedMin` parça başına hesaplanıyor

## 🆕 Aşama 2 — AddEventModal 3 Sekmeli

`src/components/modals/AddEventModal.tsx` baştan yazıldı.

### 2.1 Tür Sekmeleri (Üstte Segmented Control)
```
[ 📅 Etkinlik ]  [ ✓ Görev ]  [ 🎯 Hedef ]
```
Sekmenin altında küçük italic ipucu satırı:
- *"Sabit saatli randevu / toplantı"*
- *"Yapılacak iş — saat opsiyonel"*
- *"Büyük hedef — alt görevleri olur"*

### 2.2 📅 Etkinlik Sekmesi (Mevcut Davranış Korundu)
Ad → Tarih → Başlangıç → Bitiş → Kategori → Önem
- Validasyon: `startTime < endTime` zorunlu
- `kind: 'event'` ile kayıt

### 2.3 ✓ Görev Sekmesi (Yeni — Problem 3'ün Esas Konusu)
- **Saatsiz toggle**: "Tüm gün" işaretlenirse saat alanı gizlenir → all-day shelf'e gider
- **Tek başlangıç saati** (saatli ise) — bitiş otomatik hesaplanıyor (`time-preview` ile gösteriliyor)
- **Tahmini süre chip'leri**: 15 dk / 30 dk / 1 sa / 2 sa / 4 sa
- **Tekrar chip'leri**: Tekrar yok / Her gün / Hafta içi / Haftalık
- `kind: 'task'`, `estimatedMin`, `allDay`, `recurrence` ile kayıt

### 2.4 🎯 Hedef Sekmesi (Yeni — Büyük Hedef Container)
- Ad ("Ör: Python öğren")
- Açıklama (textarea, opsiyonel)
- Hedef tarihi
- Saat slot'u **yok** — `allDay: true` ile kayıt
- `kind: 'goal'` → calendar bunu time-block olarak göstermeyecek

### 2.5 Ortak Alanlar (Tüm Sekmelerde)
- **Kategori chip seçici**: 👤 Kişisel · 💼 İş · 📚 Okul · 🩺 Sağlık · 🏷️ Diğer

- **Önem seviyesi**: 🔴 Yüksek · 🟠 Orta · 🔵 Düşük
  - Default `'medium'` yapıldı (önceki `'high'`'tan daha gerçekçi)

### 2.6 Yeni Form Bileşeni Stilleri
`globals.css` sonuna eklendi:
- `.add-evt-modal` — daha geniş + scroll'lanabilir
- `.kind-tabs` + `.kind-tab` — segmented control görünümü
- `.kind-hint` — italic ipucu satırı
- `.toggle-row` + `.toggle-label` — checkbox toggle
- `.estimated-chips` + `.estimated-chip` — pill button grid

## 🆕 Aşama 3 — Calendar Görseli Çoğullaştırıldı

`src/components/calendar/CalendarSection.tsx` baştan yazıldı.

### 3.1 AllDayShelf Bileşeni
Gün sütunlarının **en üstünde** saatsiz görev şeridi:
- 🎂 **Doğum günü chip'leri** taşındı (eskiden ayrı `bday-banner` blokuydu)
- ✓ **Saatsiz görev chip'leri** — kategori rengiyle sol kenar, kategori ikonu, postpone rozeti, hover aksiyonları
- **Kronik (3+ ertelemiş)** görevlerde pulse animasyonlu kırmızı kenar (`pulseChronic` keyframe)

### 3.2 SlotGrid + Slot Tıklama
Saat çizgisi 1 px olduğu için tıklanabilirliği zayıftı. Çözüm:
- Görsel saat çizgisi (1 px) **+** ayrı görünmez `.hour-slot` overlay (tam saat yüksekliği)
- Slot'un üst yarısına tıklarsan `:00`, alt yarısına `:30` dakika ile pre-fill
- Tıklayınca AddEventModal o tarih ve saatle açılır
- Delete mode'da slot devre dışı

### 3.3 time-grid Wrapper (Layout Düzeltmesi)
AllDayShelf normal akışta, saatli event'ler ise absolute positioning ile day-column'un tepesinden başlıyordu → birbirinin üzerine biniyorlardı. Çözüm:
- `<div className="time-grid">` adında ayrı `position:relative` container
- AllDayShelf normal akışta üstte, time-grid altında, absolute event'ler artık time-grid'e göre konumlanıyor

### 3.4 Filtreler
- `kind === 'goal'` → calendar'da **hiç gözükmez** (sidebar'da göstermek ileri sürümlerde planlanıyor)
- `moduleType === 'birthday'` → shelf'te banner olarak
- Diğerleri `allDay` flag'ine göre shelf veya time-grid'e ayrılır

### 3.5 EventCard'da Hover Aksiyonları
EventCard ve AllDayChip üzerinde hover'da sağ üstte 3 küçük buton:
- **✓** Tamamla (yeşil) — tamamlanmışsa **↺** geri al
- **🔄** Ertele (mavi) → PostponeReasonModal'ı açar
- **✂️** Parçala (turuncu) → SplitTaskModal'ı açar

Statistics overlay'e gitmeden, **doğrudan görev kartından** ertelenebiliyor — Problem 3 için kritik.

### 3.6 Kategori Rengi
Tüm event/task kart ve chip'lerinde sol kenar = `EVENT_CATEGORY_COLORS[ev.category]`. Ertelenmiş görevlerde mevcut sarı/kırmızı kenar uyarı stili korunuyor (öncelik veriyor).

### 3.7 Kind Bazlı Görsel İpucu
- Saatli görevlerde (`kind === 'task'`) sağ kenarda küçük çizgili pattern (`::before`)
- Ad'ın başında küçük ✓ marker
- MonthView'da task'lar italic, all-day'lar saat yerine `✓` veya `•`

### 3.8 AddEventModal Preset Desteği
- `AddEventPreset` tipi export edildi: `{ date?, startTime?, endTime?, kind? }`
- `useEffect` ile modal açıldığında preset uygulanıyor
- `startTime` verilmişse otomatik Etkinlik sekmesi seçiliyor + bitiş +1 saat default

### 3.9 PlannerApp Bağlantıları
- `addPreset` state'i eklendi
- `handleSlotClick(dateStr, hour, minute)` → preset set edip modal açar
- `handleOpenAddModal()` → preset'i temizleyip modal açar (manuel + butonu için)
- CalendarSection'a `onComplete`, `onPostpone`, `onSplit`, `onSlotClick` prop'ları geçildi

### 3.10 Yeni CSS (~50 satır)
- `.allday-shelf` + `.allday-chip` + `.allday-act` — kategori, postpone, kronik, hover butonları
- `.event-card.kind-task::before` — task'lar için sağ kenar çizgi pattern'i
- `.event-card .card-actions` + `.card-act` — hover aksiyon menüsü
- `.time-grid` — flex container
- `.hour-slot` — görünmez tıklama overlay'i, hover'da mavi vurgu
- `.month-event-card.is-task` / `.is-allday` — month view ipuçları
- `pulseChronic` keyframe — kronik görevler için 2.4 sn pulse
