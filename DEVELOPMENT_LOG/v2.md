## 🆕 Eklenen Özellikler

### 1. 🔄 Erteleme Takip Sistemi
- Her etkinlik artık kaç kez ertelendiğini takip ediyor (`postponeCount`)
- Erteleme geçmişi kaydediliyor: hangi tarihten hangi tarihe, hangi nedenle (`postponeHistory[]`)
- Görevin ilk planlandığı tarih korunuyor (`originalDate`)

### 2. 🏷️ Erteleme Nedeni Seçici (Postpone Reason Modal)
Eski "Tekrar Ekle" modalı tamamen yenilendi. Kullanıcı görev ertelerken **neden** soruluyor:
- 😰 Çok büyük/karmaşık görünüyor
- ⏰ Zamanım yetmedi
- 🤷 Nereden başlayacağımı bilmiyorum
- 😴 Enerjim yoktu
- 🔄 Öncelikler değişti
- 📝 Diğer

Bu veriler AI asistan tarafından kullanılacak (farklı nedenlere farklı öneriler).

### 3. 📊 Erteleme Dashboard (Analiz Paneli)
Haftalık Tamamlanma grafiğinin altına eklendi:
- **Toplam Erteleme** sayısı
- **Kronik Görevler** (3+ kez ertelenen)
- **Sonunda Tamamlanan** (ertelenip de bitirilen görevler)
- **Gün Streak** (ertelemeden geçen gün sayısı)
- **Erteleme Nedenleri** grafiği (bar chart)
- **En Çok Ertelenen Görevler** listesi (top 3, bölme butonu ile)

### 4. 🔁 Takvimde Erteleme Göstergesi
- Ertelenen görevler takvimde **sarı 🔄 badge** ile gösteriliyor (ör: 🔄2)
- 1-2 kez ertelenen: sarı border
- 3+ kez ertelenen (kronik): kırmızı yanıp sönen efekt

### 5. ✂️ Görev Bölme / Parçalama Sistemi
Büyük görevleri küçük alt görevlere bölme:
- Görevin süresine göre otomatik parça sayısı önerisi (90dk+ → 4 parça, 60dk+ → 3, diğer → 2)
- Her alt görev için isim girişi (placeholder önerileri ile)
- "+" butonu ile ek alt görev ekleme
- Bölündüğünde: ana görev silinir, yerine zamana bölünmüş mini görevler oluşur
- Alt görevler `parentId` ve `parentName` ile bağlı

### 6. 💬 Motivasyonel Bildirimler
- Erteleme yapıldığında: `🔄 "Görev adı" taşındı` bildirimi
- 3+ erteleme: `⚠️ "Görev adı" 3x ertelendi! AI Asistan'a bak.` uyarısı
- Görev bölündüğünde: `✂️ "Görev adı" 4 parçaya bölündü!` başarı bildirimi

### Event Veri Yapısı (Güncellenen)

```javascript
{
  id: "evt_...",
  name: "Görev adı",
  date: "2026-05-09",
  startTime: "09:00",
  endTime: "11:00",
  importance: "high",
  completed: false,
  // ↓ YENİ ALANLAR ↓
  postponeCount: 0,              // Kaç kez ertelendi
  postponeHistory: [              // Erteleme geçmişi
    { from: "2026-05-05", to: "2026-05-07", reason: "too_big", timestamp: 1746... }
  ],
  originalDate: "2026-05-03",    // İlk planlandığı tarih
  subTasks: [],                   // Alt görevler (opsiyonel)
  parentId: null,                 // Alt görevse ana görevin ID'si
  parentName: null                // Alt görevse ana görevin adı
}
```

### Erteleme Neden Kodları

| Kod | Anlamı |
|-----|--------|
| `too_big` | Çok büyük/karmaşık |
| `no_time` | Zamanım yetmedi |
| `dont_know` | Nereden başlayacağımı bilmiyorum |
| `no_energy` | Enerjim yoktu |
| `priorities` | Öncelikler değişti |
| `other` | Diğer |

### AI'ın kullanabileceği veriler:
- `ev.postponeCount` → Kaç kez ertelendi
- `ev.postponeHistory[].reason` → Neden ertelendi
- `ev.originalDate` vs `ev.date` → Ne kadar süredir erteleniyor
- `ev.parentId` → Bölünmüş görev mi

### Örnek AI önerileri:
- 3+ kez ertelenen → "Bu görevi parçalara böl"
- `too_big` nedeni → "Küçük bir adımla başla, 15 dakika yeterli"
- `no_energy` nedeni → "Bu görevi enerjinin yüksek olduğu saate taşı"

## 📱 Kullanıcı Akışı (Demo Senaryosu)

1. Kullanıcı "Rapor yaz" görevini Pazartesi'ye ekler
2. Pazartesi tamamlamaz → "Tamamlanmayan Görevler" listesinde çıkar
3. "Tekrar Ekle" butonuna tıklar → **Erteleme Nedeni Modalı** açılır
4. "Çok büyük/karmaşık" seçer → Yeni tarih seçer → Erteler
5. Takvimde görevde **🔄1 badge** görünür
6. Tekrar erteler → **🔄2 badge**, tekrar → **🔄3 kırmızı yanıp sönme**
7. Dashboard'da: "3 toplam erteleme, 1 kronik görev" istatistikleri
8. Dashboard'da "En Çok Ertelenen" listesinde ✂️ butonuna tıklar
9. **Görev Bölme Modalı** açılır → 3 parçaya böler
10. Küçük görevleri tek tek tamamlar 🎉
